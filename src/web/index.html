Players (JSON)

Objeto { idioma: { sub: [...], dub: [...] } }, cada entrada con id y rule. Plantillas dentro de cada rule: {base_url} {query} {slug} {episode}. Es JSON, así que las barras de las regex van dobles (\\). Las claves de idioma deben ser códigos como TMDB los espera (ej. es-ES, en-US) — el mismo valor se usa para consultar TMDB.
